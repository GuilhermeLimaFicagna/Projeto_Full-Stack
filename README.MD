# 🚀 Projeto Full Stack - CRUD Completo

`💻 Uma aplicação Full Stack desenvolvida para praticar a construção de um CRUD completo, integrando front-end, back-end e banco de dados utilizando tecnologias modernas do mercado.`

## ⚙️ Funcionalidades

- ✅ Criar novos registros
- 📄 Listar dados cadastrados
- ✏️ Atualizar informações existentes
- ❌ Deletar registros
- 🔗 Integração completa entre front-end e back-end
- 🗄️ Manipulação de dados em banco NoSQL

## 🛠️ Tecnologias Utilizadas

### 🔙 Back-end
- Node.js
- Express
- Prisma ORM

### 🎨 Front-end
- React
- Vite

### 🗄️ Banco de Dados
- MongoDB

## 📚 Aprendizados

- 📌 Criação de API REST
- 🔄 Comunicação entre front-end e back-end
- 🧠 Uso do Prisma com banco de dados
- 🏗️ Estruturação de projetos Full Stack
- 🔁 Implementação de operações CRUD
- 🧹 Organização de código
